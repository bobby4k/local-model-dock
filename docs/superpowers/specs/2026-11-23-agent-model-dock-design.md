# Local Model Dock 设计

## 目标与范围

在 Apple Silicon Mac 和 Linux 上，根据机器资源发现、选择并运行适合基础编码及简单知识问答的小模型，为 Agent 提供 OpenAI 兼容接口。Intel Mac 不支持。项目主体采用 Python 3.11+；Apple Silicon 使用 oMLX，Linux 使用 Ollama。

两种平台默认允许内网访问并启用 API 密钥。默认不意味着网络自动隔离：安装文档必须说明监听地址、防火墙和公网暴露风险。HTTP 不加密请求、响应或密钥；如需加密，由部署环境提供 HTTPS。不能假设 Ollama 自身验证 OpenAI API 密钥；实施时须验证并提供受保护的接入方式，避免后端绕过认证。

## 模型发现和推荐

- 检测硬件、可用内存、磁盘空间和后端兼容性；未知资源不得被当成充足。
- 运行时从线上模型库发现模型，包括预置清单之外的模型。默认优先 DeepSeek 和 Qwen，顺序通过 `.env` 配置；不合适时可推荐其他家族。
- 只选择混合专家模型（MoE）；不能可靠确认架构为 MoE 的模型不进入正式推荐，待验证候选须明确标示架构是否已确认。没有符合条件的 MoE 模型时提示用户，不自动回退到稠密模型。
- 展示模型来源、许可证、资源估计及未知项。名称、热度或模型卡的声明不能证明模型品质或工具调用能力。
- 正式推荐的模型须通过与目标后端相匹配的工具调用测试。新发现且没有可信测试记录的模型先列为待验证候选，须经用户确认下载，测试通过才可正式推荐并切换。已有可信测试记录应绑定模型和后端的具体版本，实施时定义记录及验证方法。
- 筛选时检查格式和架构的后端兼容性、可用内存与运行余量、实际剩余磁盘空间，以及来源、许可证和访问条件；未知项须标明，不能当作满足条件。20 GB 预算为提醒阈值，不是淘汰条件。
- 合格候选先按 `.env` 配置的家族优先级排序；同一家族优先级内，优先可信的编码和工具调用测试结果，再综合本机资源余量、预期速度及上下文需求。来源可信度、下载量和更新时间仅作为辅助参考。展示排序理由和未知项，不把模型大小、热度或修改时间当作质量保证。具体测试方法和可量化规则须在实施前确定。
- 首次默认自动下载，先展示推荐；仅当有符合条件的已验证候选、资源估计可靠且预计不超过预算时执行。否则提示原因并等待用户处理或确认；下载后仍须验证才能启用。

## 存储和预算

`.env` 中的预算默认 20 GB，可修改；它是提醒阈值，不是硬限制。统计项目管理的当前模型、最近一个旧模型、候选模型、下载临时文件和 SSD 缓存。预计首次下载超过阈值时提醒并等待确认；实际超过时提醒。更新无论预算如何均须事先确认。实际磁盘空间不足时不能继续下载，应提示调整配置或释放空间。

不删除非本项目管理的文件或模型。更新期间必须保留当前模型及最近的旧模型，不能为更新先删除唯一的回退版本。模型文件、临时文件及后端缓存的可观测性和超预算提醒需实际验证；不可可靠估算时不得静默自动下载。

Apple Silicon 使用所选 oMLX 版本实际支持的内存及 SSD 缓存优化；为 SSD 缓存设置明确容量，考虑预算，限制文件权限并说明缓存可能包含对话内容。不承诺未经验证的性能改善。

## 更新、确认和回退

- 提供手动检查命令；周期由用户通过 crontab 或其他方式配置，项目不修改定时任务。
- 检查当前模型版本，也主动发现更适合机器的其他模型。检查本身不下载或切换。
- 检查结果需通知用户，下载更新和切换前须获得针对候选的确认。确认后重新检查空间、下载并验证；失败或中断时继续使用当前模型。
- Telegram 可选：Bot Token 在 `.env` 定义，未定义即关闭；配置允许确认的用户 ID 和聊天 ID，缺少授权配置时拒绝 Telegram 确认。确认绑定候选和有效期、防止重放；Token 不进入日志或版本控制。未启用 Telegram 时提供本地命令查看及确认更新。
- 保留最近一个旧模型并提供手动回退；版本使用可核验的不可变标识。禁止清理不属于项目的文件。更新冲突、重启恢复与后端存储行为须测试。
- Agent 使用稳定模型名；切换后新请求使用新模型，已经开始的请求尽量完成。切换及请求排空的具体机制须依据后端实测确定。

## 验收与实施约束

命令行支持 `start`、`update`、`stop`、`restart`，并提供检查、确认和回退方式；`update` 不得绕过候选通知与确认。文档覆盖 macOS、Linux、Agent 接入、cron、Telegram、安全、恢复和卸载。API 至少测试聊天、流式输出和工具调用；列明兼容子集，不宣称支持全部 OpenAI API。测试硬件及元数据未知、磁盘不足、预算超出、网络故障、拒绝或重复确认、验证失败、重启和回退等情况。

先用模拟后端覆盖正常与失败路径，再在可获得的 Apple Silicon 与 Linux 机器上验证；明确记录未测试的平台。候选模型质量、速度、上下文和工具调用效果不能仅根据线上元数据承诺。未验证功能应标为限制，不得伪称已实现。

## 官方资料（2026-11-23 核对）

- [oMLX](https://github.com/jundot/omlx)：Apple Silicon、macOS 15+；支持内存/SSD 分层缓存、固定 SSD 缓存上限和模型别名。具体版本及实际表现须验证。
- [Ollama macOS 支持](https://docs.ollama.com/macos)、[GPU 支持](https://docs.ollama.com/gpu)及 [OpenAI 兼容性](https://docs.ollama.com/api/openai-compatibility)：兼容 API 是子集，硬件支持依赖设备与驱动。
- [Hugging Face Hub API](https://huggingface.co/docs/hub/en/api) 和 [Ollama 本地模型列表](https://docs.ollama.com/api/tags)：可获取部分模型元数据及版本标识，但不构成品质验证。
